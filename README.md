# Hogar Por Favor

Primera presencia pública de hogarporfavor.com, un proyecto de Imperio. HTML, CSS y JavaScript sin dependencias de compilación, compatible con Hostinger Premium PHP/HTML.

## Estado real

Sitio de lanzamiento adaptable con marca original, búsqueda con estado vacío, consejos de seguridad, privacidad y preparación de anuncios. Los borradores se guardan únicamente en el navegador y pueden descargarse. No hay propiedades ficticias, cuentas, mensajes, verificaciones ni publicaciones activas. Estas capacidades requieren una siguiente etapa con servidor, base de datos, moderación y avisos adecuados antes de recibir datos reales.

## Publicación en Hostinger

Subir index.html, style.css, app.js, logo.png, favicon.png, hogar.jpg, robots.txt, sitemap.xml y .htaccess a public_html. No subir respaldos ni credenciales. El archivo index.html debe quedar directamente en public_html.

## Desarrollo

Servir la carpeta con un servidor estático. No necesita npm install. Ejecutar `node --check app.js` para comprobar la sintaxis.

## Recursos

Logo y favicon proporcionados por el propietario. Fotografía: Unsplash, https://images.unsplash.com/photo-1600596542815-ffad4c1539a9 . Tipografías DM Sans y Manrope servidas por Google Fonts; Arial como alternativa.

El repositorio no configura sincronización automática con Hostinger. Los cambios se despliegan por carga de archivos o mediante la función Git de hPanel cuando esté configurada.
